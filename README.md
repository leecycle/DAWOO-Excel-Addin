# DAWOO Excel Add-in

![DAWOO Excel Add-in 9.0.3 리본 메뉴](docs/images/dawoo-excel-addin-ribbon-9.0.3.png)

Windows용 Excel VBA 추가 기능입니다.

## 설치

1. 파일을 다운로드합니다.
2. ZIP 파일의 압축을 완전히 풉니다.
3. Excel과 VBA 편집기를 모두 종료합니다.
4. `Install.exe`를 실행합니다.
5. 설치 후 Excel을 다시 실행합니다.

## 실행

Excel의 **추가 기능** 탭에서 DAWOO 리본 메뉴를 사용합니다.

- **위 / 아래**: 선택한 위치를 기준으로 합계를 처리합니다.
- **유틸 / 페이지 / 사진 / 서식 / 파일정리**: 필요한 작업 메뉴를 선택합니다.
- **환경설정**: 설치 폴더, 백업 폴더, 업데이트 채널과 빠른 실행 도구 모음을 설정합니다.
- **업데이트**: GitHub에서 새 버전을 확인하고 설치합니다.
