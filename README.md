# DAWOO Excel Add-in

Windows Excel용 DAWOO VBA 추가기능입니다.

## 설치

1. 최신 [GitHub Release](https://github.com/leecycle/DAWOO-Excel-Addin/releases/latest)에서 DAWOO_Excel_Addin_*.zip을 다운로드합니다.
2. ZIP을 완전히 압축 해제합니다.
3. Excel과 VBA 편집기를 모두 종료합니다.
4. INSTALL.cmd를 실행합니다.

설치 위치: C:\My DATA\00 기본설정\EXCEL\추가기능\다우추가기능.xlam

## 파일정리

페이지 메뉴 옆의 **파일정리** 메뉴에서 상태 검사, 안전 정리, 고급 선택 정리, 사용자 지정 스타일 전체 삭제를 실행할 수 있습니다. 변경 작업 전에는 통합문서 폴더의 Backup 폴더에 원본을 자동 백업합니다.

## 업데이트

Excel의 **추가 기능** 탭에서 **업데이트 확인** 버튼을 눌렀을 때만 새 버전을 확인합니다. 자동 또는 백그라운드 업데이트는 실행하지 않습니다.

다운로드한 업데이트 ZIP은 SHA-256을 검증한 후 Excel이 종료되면 설치됩니다.
