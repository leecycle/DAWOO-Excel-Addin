DAWOO Excel Add-in 6.4.0

- 페이지 메뉴 옆에 Excel 문서+빗자루 아이콘의 '파일정리' 메뉴를 추가했습니다.
- 파일 상태 검사로 사용 범위, 사용자 지정 스타일, 깨진/숨겨진 이름, 외부 링크, 연결, 개체와 메모를 확인합니다.
- 안전 정리는 깨진 이름과 실제 데이터 뒤의 불필요한 서식을 정리하고 UsedRange를 재설정합니다.
- 고급 선택 정리는 숨겨진 이름, 외부 링크/연결, 메모, 그림을 항목별로 선택해 정리합니다.
- Excel 기본 스타일을 제외한 사용자 지정 스타일 전체 삭제 기능을 추가했습니다.
- 변경 작업 전 원본 파일과 같은 폴더의 Backup 폴더에 자동 백업합니다.
- 인쇄영역, 반복 제목, 필터 이름과 차트, 버튼, 컨트롤은 보존합니다.
- 6.3.3의 다중 워크시트 페이지/머리글 적용과 기존 기능을 그대로 유지합니다.
