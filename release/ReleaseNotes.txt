DAWOO Excel Add-in 7.1.0

- GitHub Release의 Pre-release 상태를 기준으로 정식판과 베타판을 직접 구분하도록 업데이트 방식을 변경했습니다.
- 정식 채널은 최신 정식 Release를 확인하고, 베타 채널은 정식판과 베타판을 포함한 최신 Release를 확인합니다.
- Version.ini 및 Version-Test.ini 대신 Release 태그, 첨부 ZIP 주소와 GitHub SHA-256을 직접 사용합니다.
- 7.0.0 이후 베타 테스트에서 검증한 변경 사항을 정식 버전으로 통합했습니다.
- 사진대지를 새 04 사진대지.xlsx 양식으로 교체했습니다.
- 환경설정·업데이트 / 도움말·버전정보 버튼을 2×2로 배치했습니다.
- 유틸과 파일정리 아이콘을 파랑·회색 디자인으로 개선했습니다.
- 도움말을 메뉴별 상세 사용법과 주의사항으로 확장하고 스크롤 창으로 변경했습니다.
- 빠른 실행 도구 모음 적용과 기존 Excel.officeUI 자동 백업을 추가했습니다.
- Excel 종료 대기 후 자동 설치 과정을 개선했습니다.
- SaveCopyAs 방식으로 파일 액세스 오류를 수정했습니다.
- 업데이트 설치 중 한글 XLAM 파일명이 깨지는 오류를 수정하고 INSTALL.ps1의 ANSI/CP949 호환성을 유지했습니다.
- 7.0.0의 기존 리본, 페이지 설정, 사진 삽입, 서식, 파일정리 및 백업 기능은 그대로 유지합니다.
